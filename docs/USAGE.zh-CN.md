# Paper Workbench for Zotero 使用指南

[English](USAGE.md) | 中文

Paper Workbench for Zotero 是非官方社区插件，把 Zotero PDF 阅读器整理成可拖动的专注工作台：

```text
PDF 论文 | 划词翻译 | 笔记 + AI 对话
```

本项目与 Zotero、OpenAI 不存在隶属、背书或官方合作关系。

## 1. 安装

Windows、macOS 和 Linux 使用同一个 XPI。

1. 从[最新 Release](https://github.com/TJR-USTC-HUB/paper-workbench-for-zotero/releases/latest)下载 `paper-workbench-for-zotero.xpi`。
2. 在 Zotero 中打开**工具 → 插件**。
3. 打开齿轮菜单，选择**从文件安装插件…**。
4. 选择 XPI；如有提示，请重新启动 Zotero。
5. 打开一个 PDF 附件。

插件支持 Zotero 7–10。正常使用不需要 Node.js；只有源码开发需要。

## 2. 登录模型端点

插件第一次打开时默认未登录。登录界面只填写两项：

- **Base URL**：兼容 OpenAI 服务的 `/v1` 地址。
- **API Key**：该服务签发的访问凭证。

此处故意不显示模型 ID 输入框。点击**登录**后，插件会：

1. 请求所配置端点的 `GET /models`；
2. 如果存在 `gpt-6.1-sol` 则优先选择，否则选择返回的第一个模型；
3. 验证所选模型可以响应；
4. 把端点、密钥、模型列表和登录状态保存在当前本机 Zotero 配置中。

登录后，在输入框上方选择当前模型及其支持的思考强度。根据模型不同，可用档位可能包括 `low`、`medium`、`high`、`xhigh` 和 `max`。

点击**退出登录**会取消活动请求，删除保存的 API Key 和当前模型选择，并让 AI 栏与翻译栏一起恢复未登录状态。

## 3. 使用三栏工作台

### 调整区域大小

- 拖动 PDF 栏与翻译栏之间的边界。
- 拖动翻译栏与工作栏之间的边界。
- 打开笔记后，拖动笔记与对话之间的横向边界。

插件会记住尺寸并在下次恢复。每一栏都有最小宽度，内容不会相互覆盖。

### 自动翻译 PDF 选区

1. 在已打开的 PDF 中选中英文句子或段落。
2. 中间栏会自动显示选中原文和大字号中文译文。
3. 选择另一段文字即可替换原文和译文。

翻译使用当前已登录端点。未登录时不会发送任何内容。翻译栏会明确显示等待、加载、未登录和错误状态。

### 询问选中的段落

1. 在 PDF 中准确选中需要讨论的原文。
2. 可选择模型和思考强度。
3. 输入问题，或直接发送默认的“解释选区”请求。
4. Enter 发送，Shift+Enter 换行。

专注对话只发送实时 PDF 选区和本次问题，不会附加全文、邻近段落、旧对话、联网搜索、工具结果或其他 Zotero 条目。旧消息会保留在本地界面中，但不会重放到下一次专注请求。

没有实时选区或尚未登录时，发送按钮保持禁用。

### 使用笔记

1. 点击工作栏工具条中的**笔记**。
2. 选择已有子笔记，或点击**新建笔记**。
3. 在工作栏上半部分编辑笔记。
4. 需要更多空间时，拖动笔记与对话之间的横向边界。
5. 完成后点击**关闭笔记**。

切换或关闭笔记前，插件会先保存当前内容。关闭笔记后，对话自动占满整个工作栏。打开、切换或关闭笔记不会清空对话或输入框草稿。

## 4. 界面行为

- 用户消息靠右，AI 回答靠左。
- 翻译栏与对话栏使用统一的暖中性色调。
- 专注界面会隐藏旧版全文、队列、Web Agent、工具、素材和调试控件。
- 模型和思考强度在登录后的对话界面中选择。

## 5. 数据与隐私

- API Key 保存在当前本机 Zotero 配置中。
- 划词翻译会把选中文字发送到你配置的端点。
- 专注对话会把选中文字和本次问题发送到该端点。
- Zotero 笔记和文库数据仍由 Zotero 管理。
- API Key 不会写入源码、XPI 或 Release 压缩包。

本机 Zotero 配置目录和导出的配置备份可能包含凭证，请勿公开。使用前请阅读所配置服务的隐私政策和数据保留条款。

## 6. 故障排查

### 登录失败

- 确认 Base URL 包含服务的 API 前缀，通常为 `/v1`。
- 确认密钥有权调用 `GET /models`，以及兼容 Responses 或 Chat Completions 的接口。
- 检查代理、VPN、防火墙和证书设置。
- 如果服务不提供 `/models`，当前专注登录流程就无法自动发现模型。

### 没有出现翻译

- 确认已经登录。
- 选中真实 PDF 文字，而不是只有图片的扫描区域。
- 尝试更短的选区，并检查模型端点是否正常响应。

### 发送按钮不可用

- 保持当前 PDF 中存在实时文本选区。
- 确认登录成功并已选择模型。
- 等待正在生成的回答结束。

### 笔记没有出现

- 重新点击**笔记**并选择目标子笔记。
- 确认当前 Zotero 条目可编辑。
- 正常关闭笔记区域，让最后一次保存完成。

## 7. 更新或卸载

更新时，直接安装新版 XPI 覆盖现有版本；如有提示，请重新启动 Zotero。

卸载时，在**工具 → 插件**中打开本插件菜单，选择**移除**；如有提示，请重新启动。如果希望插件主动清除保存的 API Key，请先退出登录。移除插件不会删除 Zotero 笔记或文库条目。
